# Чеклист актуализации ROADMAP

Этот чеклист нужно применять после каждой завершенной задачи, которая меняет продуктовый scope, архитектуру, Bot API поверхность, ограничения или ближайшие планы.

## Когда обновлять

Обновляй `ROADMAP.md`, если задача:

- добавила, удалила или изменила Bot API метод;
- изменила формат `Update`, `Message`, `Chat`, `User`, `WebhookInfo` или другого Telegram-like payload;
- изменила webhook, Long Polling, очередь updates, storage, import/export или UI-сценарий чата;
- закрыла пункт roadmap, изменила статус этапа или добавила новую зависимость;
- изменила ограничения проекта или сделала ранее задокументированное ограничение неактуальным;
- выявила следующий практичный Bot API метод или архитектурную задачу.

## Что проверить

Перед коммитом сверь:

- Bot API surface: список поддерживаемых endpoints, методы HTTP, обязательные параметры, статусы ошибок и `docs/limitations.md`;
- статусы этапов: выполненные пункты, частично выполненные пункты, перенесенные задачи и причины переноса;
- ограничения: media upload/download, command scopes, language-specific commands, webhook retries/timeouts, Long Polling timeout, group chat модель, import/export;
- следующие методы: какие Telegram Bot API методы логично реализовать дальше и почему они важны для локальной разработки;
- архитектура: новые controllers/services/helpers, изменения тестовой стратегии и ссылки на ADR;
- документация запуска: порты, env vars, Docker Compose usage и fake token examples.

## Как фиксировать изменения

- Если задача закрывает пункт roadmap, пометь его выполненным или переформулируй остаток как отдельную будущую задачу.
- Если реализация намеренно не делалась, запиши принятое решение и причину в roadmap, ADR или `docs/limitations.md`.
- Если появился новый приоритет, добавь его в ближайший релевантный этап, а не в конец без контекста.
- Не добавляй расплывчатые пункты вроде "улучшить совместимость"; указывай конкретный метод, payload, UI-сценарий или проверку.
- Если `ROADMAP.md` не требует изменения, это можно коротко отметить в `AI_CURRENT_CONTEXT.md`.
