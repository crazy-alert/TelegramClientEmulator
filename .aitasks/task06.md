# Вкладка updates в интерфейсе

Источник: `ROADMAP.md`, Этап 6.

## Цель

Добавить навигационный раздел для updates.

## Ожидаемый результат

- В layout есть ссылки на новые разделы.
- `/updates` показывает список updates с фильтрами.
- `/delivery-attempts` уже реализован отдельной задачей; при необходимости оставить ссылку на него в навигации.
- Данные доступны без ручного чтения SQLite/logs.
