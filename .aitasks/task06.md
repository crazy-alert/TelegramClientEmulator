# Вкладки updates и delivery attempts в интерфейсе

Источник: `ROADMAP.md`, Этап 6.

## Цель

Добавить навигационные разделы для updates и delivery attempts.

## Ожидаемый результат

- В layout есть ссылки на новые разделы.
- `/updates` показывает список updates с фильтрами.
- `/delivery-attempts` интегрирован с экраном delivery attempts.
- Данные доступны без ручного чтения SQLite/logs.
