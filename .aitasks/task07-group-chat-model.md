# Задача 07: Отдельная модель group chat

## Цель

Подготовить более каноничную модель group/supergroup chat вместо нескольких `profiles` с общим `chat_id`.

## Ожидаемый результат

- Продумана и реализована минимальная сущность `chats` или `groups` с `chat_id`, `type`, `title`.
- Profiles связаны с group через membership table или аналогичный механизм.
- `/chat` сохраняет быстрый сценарий выбора отправителя.
- Import/export остается backward-compatible.
- Добавлены focused/integration tests.

## Ограничения

- Задача крупная: сначала подготовить схему и один UI/API сценарий, если полный перенос слишком широк.
