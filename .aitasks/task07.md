# Inspector request/response

Источник: `ROADMAP.md`, Этап 6.

## Цель

Расширить inspector так, чтобы можно было смотреть request/response Bot API и webhook событий.

## Ожидаемый результат

- Видны последние Bot API requests из HTTP-логов или отдельного хранилища.
- Видны response status/body.
- Есть фильтр по bot token/method, без раскрытия реальных секретов.
- Документация описывает ограничения инспектора.
