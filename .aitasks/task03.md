# Настройки webhook timeout в UI

Источник: `ROADMAP.md`, Этап 4.

## Цель

Сделать timeout webhook-доставки видимым и настраиваемым из интерфейса.

## Ожидаемый результат

- Пользователь видит текущий webhook timeout.
- Можно задать значение в допустимом диапазоне без изменения production-файлов.
- Значение используется `WebhookDeliveryService` или текущей логикой доставки.
- Документация описывает env/default и UI-настройку.
- Добавлены тесты для валидации диапазона.
