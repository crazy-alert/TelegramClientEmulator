# HTMX polling для обновления чата

Источник: `ROADMAP.md`, Этап 6.

## Цель

Добавить HTMX polling для обновления истории чата без ручной перезагрузки страницы.

## Ожидаемый результат

- История сообщений обновляется периодически при открытом `/chat`.
- Polling не ломает выбранную пару `profile_id`/`bot_id`.
- Raw inspector и клавиатуры остаются работоспособными.
- Добавлена документация или заметка в README/ROADMAP.
