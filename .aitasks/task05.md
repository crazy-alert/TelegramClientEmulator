# Inline validation форм

Источник: `ROADMAP.md`, Этап 6.

## Цель

Добавить inline validation для форм ботов, пользователей и ключевых Bot API/UI действий.

## Ожидаемый результат

- Некорректные значения показываются рядом с полем, а не только приводят к общему redirect/error.
- Валидация не добавляет неканоничные Bot API shortcuts.
- Добавлены тесты на основные ошибки формы.
