# Задача 04: Декомпозиция Application

## Цель

Сократить ответственность `Application`, вынеся UI/admin routes в отдельные контроллеры.

## Ожидаемый результат

- Добавлены контроллеры для одного или нескольких независимых срезов: `/bots`, `/profiles`, import/export, inspector routes.
- `Application` остается composition root и route dispatcher.
- Поведение HTTP routes не меняется.
- Добавлены или сохранены relevant tests.
- Обновлена архитектурная документация.

## Ограничения

- Если задача получается большой, сначала вынести только один срез, например bots или import/export, и создать подзадачи для остальных.
