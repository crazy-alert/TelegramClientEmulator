# Import/export ботов и пользователей

Источник: `ROADMAP.md`, Этап 6 и `AI_PROPOSALS.md`.

## Цель

Добавить экспорт и импорт тестовых ботов и пользователей.

## Ожидаемый результат

- Экспорт JSON для bots/profiles без истории сообщений.
- Импорт JSON с валидацией конфликтов token, user_id и chat_id.
- UI-кнопки на страницах ботов/пользователей или отдельный экран.
- Тесты на round-trip export/import.
