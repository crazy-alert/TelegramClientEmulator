# Group/supergroup: роли участников

Цель: добавить базовую модель ролей участников group/supergroup для локального тестирования admin-related сценариев.

Ожидаемый результат:

- Для участника group/supergroup можно задать роль: обычный участник или администратор.
- Роли хранятся в нормализованной модели membership и доступны UI группы.
- Роли не должны менять каноничные Bot API ответы без отдельной реализации конкретного метода.
- Command scopes admin-only могут использовать эту модель только если это не ломает текущую exact-семантику Bot API; иначе оставить как документированную основу для будущего метода.
- Обновить tests и документацию/roadmap.

Ограничения:

- Не моделировать все Telegram permissions заранее.
- Не добавлять настоящую Telegram-интеграцию.
