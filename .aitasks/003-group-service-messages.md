# Group/supergroup: service messages

Цель: добавить локальные service messages для основных событий group/supergroup, чтобы история чата лучше отражала изменения участников и названия.

Ожидаемый результат:

- При изменении title группы создается видимое service message в истории, если изменение выполнено через UI.
- При добавлении или удалении участника создается видимое service message в истории группы.
- Service messages хранят Telegram-like raw payload, но не должны создавать Bot API update без явного решения; если update не создается, это должно быть задокументировано.
- UI чата отображает service messages отличимо от сообщений пользователя/бота.
- Обновить tests и документацию/roadmap.

Ограничения:

- Не добавлять сложные service events сверх title/member add/remove.
- Не ломать существующую историю сообщений и очистку чата.
