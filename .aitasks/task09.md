# Очистка истории по пользователю или боту

Источник: `ROADMAP.md`, Этап 6.

## Цель

Добавить безопасную очистку истории сообщений и updates для выбранного пользователя/бота.

## Ожидаемый результат

- Можно очистить историю конкретного диалога.
- Можно очистить pending/confirmed updates выбранного бота.
- Операция требует явного подтверждения в UI.
- Добавлены тесты на удаление только выбранной области данных.
