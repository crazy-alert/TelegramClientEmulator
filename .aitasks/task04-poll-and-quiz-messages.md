# Задача 04: Poll/quiz сообщения

## Цель
Добавить базовый `sendPoll` для исходящих сообщений бота.

## Ожидаемый результат
- Метод принимает `chat_id`, `question`, `options` и базовые optional параметры poll/quiz.
- Возвращается Telegram-like `Message.poll`.
- UI отображает poll как компактный read-only блок.
- Добавлены тесты валидных/невалидных options и успешного сохранения.
- Документация обновлена.

## Примечания
- Интерактивное голосование пользователя можно вынести в отдельную задачу, если потребуется.
