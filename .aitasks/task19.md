# Решить вопрос micro-framework

Источник: `ROADMAP.md`, открытые решения.

## Цель

Оценить, нужен ли micro-framework после роста Bot API surface.

## Ожидаемый результат

- Краткий ADR/раздел документации с вариантами: оставить custom router, Slim, Symfony components или другое.
- Учтены Docker-first, простота, тестируемость и размер проекта.
- Без внедрения framework, если нет явной необходимости.
