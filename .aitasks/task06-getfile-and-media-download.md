# Задача 06: `getFile` и локальная отдача media

## Цель
Добавить минимальную совместимость с `getFile` и скачиванием локально сохраненных media.

## Ожидаемый результат
- `getFile` возвращает Telegram-like `File` для media, сохраненных в эмуляторе.
- Локальная ссылка на файл работает внутри Docker-first workflow.
- Реализованы проверки доступа только к файлам media-хранилища.
- Добавлены тесты `getFile`, неизвестного `file_id` и path traversal.
- Документация обновлена.

## Примечания
- Не подключаться к настоящему Telegram.
