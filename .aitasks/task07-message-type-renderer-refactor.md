# Задача 07: Унификация renderer для типов сообщений

## Цель
После добавления нескольких типов сообщений вынести повторяющийся rendering raw payload из `templates/chat/index.php` в более явную структуру.

## Ожидаемый результат
- В шаблоне чата остается минимум логики определения типа сообщения.
- Для каждого поддержанного типа есть единый формат отображения.
- Тесты UI продолжают проверять ключевые типы.
- Документация архитектуры обновлена, если появляется новый helper/service.

## Примечания
- Не делать этот refactor раньше функциональных задач, чтобы не создавать абстракцию без достаточного набора типов.
