# Задача 02: Прием structured сообщений от пользователя в UI

## Цель
Добавить в `/chat` компактный ввод пользовательских сообщений не только текстом, но и structured payload:

- фото по URL/file_id;
- документ по URL/file_id;
- геопозиция;
- контакт.

## Ожидаемый результат
- Пользователь может отправить эти типы из веб-интерфейса эмулятора.
- Созданный update содержит Telegram-like `message.photo`, `message.document`, `message.location`, `message.contact`.
- Webhook и Long Polling получают одинаковый payload.
- UI остается лаконичным: дополнительные формы спрятаны в раскрывающийся блок или компактный переключатель.
- Добавлены тесты генерации update payload и HTML/DOM smoke.

## Примечания
- Не делать multipart upload в этой задаче.
- Для фото/документа использовать строковый URL/file_id как уже поддержано для bot replies.
